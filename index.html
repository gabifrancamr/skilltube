Adicionar playlist do YouTube

Cole o link de uma playlist pública. O Skill Tube extrai o parâmetro list e reproduz com o player oficial. Não é necessário alterar arquivos do projeto.

Formatos aceitos: /playlist?list=…, watch?v=…&list=… ou embed/videoseries?list=…

Processando playlist…

Boas práticas

  • Use playlists públicas. Privadas ou removidas não carregam no player.
  • Links de vídeo sem list= são rejeitados.
  • Títulos oficiais das aulas importadas podem aparecer como “Aula N” até o player sincronizar.
  • Metadados completos exigem YouTube Data API v3 (chave no backend — não no frontend).
  • Não há sincronização entre dispositivos: o localStorage é local.
